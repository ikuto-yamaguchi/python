# Delayed Counterfactual Consolidation

## 直近の失敗

PR #133では、optimizerをAdamWからMuon系更新へ替えるだけでGRU、Transformer、RWKV-7、DeltaNetの性能順位と学習可能性が大きく変化した。しかし、改善は主に局所記憶やparityへ集中し、算術・因果・計画・自由日本語へ共有されなかった。

最大ボトルネックは、候補更新を即時にモデルへ定着させると、その更新が別文脈・別表現・別能力で有害かどうかを判断できないことにある。

## 仮説

`Delayed Counterfactual Consolidation` は、観測から作った高速記憶候補を即時に長期記憶へ書かず、短期隔離領域へ保持する。一定量の未来観測後、候補が以下を同時に満たす場合だけ長期記憶へ統合する。

1. 最近の複数観測の予測損失を減らす。
2. 語彙記号を盲目的に置換した反実仮想リプレイでも損失を減らす。
3. 問題種別ラベル、能力別分岐、正解候補検索を使わない。

これは新しい巨大ニューラル層ではなく、**記憶更新の保存則**についての仮説である。

## 実装境界

- UTF-8 2〜4 byte n-gramの固定64次元疎ハッシュ。
- 64×29の単一高速記憶行列。
- 出力候補数29。
- 全能力で同一の読み出しと書き込み則。
- baselineは全候補を即時保存する`always`。
- 実験方式は32候補遅延、最大24観測リプレイ、1候補あたり4観測と盲目的記号置換を審査する。
- RAG、外部LLM、タスクラベル、正解ラベルの推論時参照、問題別分岐は使用しない。

この実装は意味表現を持たず、文字特徴から直接1 tokenを予測する。したがって、統合ゲートに失敗した場合は文字表面記憶の限界として棄却する。

## 実験

- 学習量: 128 / 512 / 2048
- seed: 1 / 7 / 19
- 混合能力: 上書き記憶、剰余加算、単純因果、単純計画
- 反例: A〜Dと色語を盲目的に置換した未見入力
- 統合ゲート: 自由対話、指示遂行、読解、推論、計画、因果・反実仮想、自由記述、長期対話、継続学習
- 測定: 精度、反実仮想精度、候補数、採用・棄却数、読み出し量、モデルbyte、Peak RSS、学習時間、推論時間

最大規模で遅延統合は平均339候補を採用し、1678候補を棄却した。即時保存より通常・反実仮想精度は約3ポイント高い。一方で学習時間は約19倍となり、自由日本語統合ゲートは偶然一致を除けば成立していない。

## 構造的判定

部分仮説は限定的に支持される。

- 将来リプレイで更新を審査すると、無差別保存より局所混合課題と記号置換反例で改善した。
- 候補の約83%を棄却し、モデルサイズは約31KBに収まった。

しかし、知能原理としては不十分である。

- 審査コストが学習量とともに増え、2048例で即時保存の約19倍。
- 文字n-gram表現のため、自由日本語へ意味転移しない。
- 統合ゲートは成立せず、自由生成もできない。
- 盲目的置換で改善しても、意味的反実仮想を理解した証拠ではない。

したがって、`更新を遅延し、複数未来で検証してから保存する`という保存則だけを候補部品として残し、現在の文字ハッシュ実装を汎用知能経路としては棄却する。
