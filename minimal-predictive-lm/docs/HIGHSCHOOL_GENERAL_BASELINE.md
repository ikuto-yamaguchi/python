# Baseline to measure before any further merge

The next integration run must report one table with the following columns for every axis: answered, correct, accuracy, coverage, selective accuracy, serialized bytes, peak RSS, candidates, feature reads, estimated operations, training time, and inference latency.

The required axes are:

- ordinary Japanese single-exposure learning;
- multi-paragraph reading;
- arithmetic with verification;
- scientific causal prediction;
- social and temporal integration;
- counterfactual revision;
- constraint planning;
- source-grounded explanation;
- long dialogue correction;
- continual cross-domain learning;
- unknown-expression abstention;
- untouched-domain and wording transfer.

The current baseline is intentionally marked **unmeasured** rather than inferred from unrelated local gates. No future change may claim progress toward high-school intelligence until this integrated baseline exists and is rerun on the same frozen data.
