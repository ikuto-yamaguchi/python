# CAP-GEN-002 latent-generator identifiability boundary

## Proposition 1: latent-coordinate conjugacy

Assume observations are generated by

```
z_{t+1} = g_a(z_t)
x_t = d(z_t)
```

where `a` selects a generator.  For any invertible coordinate transform `h`, define

```
z'_t = h(z_t)
g'_a = h o g_a o h^-1
d' = d o h^-1.
```

Then for every initial state and every generator word,

```
d'(g'_{a_t}(...g'_{a_1}(z'_0)))
= d(g_{a_t}(...g_{a_1}(z_0))).
```

### Proof

Substitute the definitions.  Adjacent `h^-1 o h` terms cancel at every step, and the
outer decoder cancels the final `h`.  Therefore the complete observable trajectory is
identical.  The repository test verifies the equality exactly over rational affine
systems, but the argument holds for arbitrary bijective `h`.

### Consequence

The latent coordinates and generator parameters are not identifiable from observation
trajectories alone.  An internal axis, neuron, or operator cannot be called the true
meaning merely because it predicts the data.  Claims must be invariant under latent
coordinate changes, or additional assumptions must reduce the equivalence class.

## Proposition 2: macro-boundary ambiguity

Suppose an observed aggregate map is `F = A o B`.  For any invertible `h`,

```
F = (A o h^-1) o (h o B).
```

Thus endpoint observations do not uniquely determine where one reusable macro ends and
the next begins.

### Consequence

A macro learner can invent many equally predictive libraries.  A claimed discovered
concept is unsupported unless one of the following holds:

- interventions expose intermediate states;
- independent environments or auxiliary variables break the symmetry;
- a frozen canonical coding rule selects one behavioral equivalence class;
- the claim is restricted to observable behavior and resource cost, not latent identity.

## Proposition 3: exponential composition count is insufficient

If `m` generators form distinguishable fixed-length words, there are `m^T` observable
words of length `T`, encoded using `T ceil(log2 m)` program bits plus fixed generator
bits.  This proves combinatorial diversity, not semantic generality.

An affine base-`m` address encoder already satisfies the count without learning useful
abstractions.  Therefore exponential word growth cannot be used as evidence of
LLM-like representation learning.

## Required invariant claim language

CAP-GEN-002 may report:

- observable predictive equivalence classes;
- cross-domain transfer under frozen evaluation;
- executable bits, induction/inference operations, and peak memory;
- robustness to latent reparameterization;
- a canonical minimal code when uniqueness is actually demonstrated.

It may not report:

- recovery of the true latent concepts from prediction alone;
- unique generator discovery without an identifiability theorem;
- novelty from exponential composition count alone.

## Next theorem target

Find the weakest additional information that identifies a minimal generator grammar up
to a declared equivalence relation.  Candidate information sources are mixed
environments, temporal nonstationarity, sparse interventions, and independently
changing auxiliary signals.  The target must be stronger than assuming task labels or
hand-supplied operator boundaries.

A useful theorem must state:

1. the observable data-generating assumptions;
2. the exact remaining equivalence class, such as permutation, scaling, or conjugacy;
3. sample or support conditions;
4. executable and computational resources required by the estimator;
5. a counterexample when any essential assumption is removed.
