# Exchange Binding Closure 001

## 直近の失敗

PR #119は頻出する文字差分を意味イベントとして保存し、学習量とともにイベント数だけが増えた。PR #120は別文脈へ移植できる文字残差だけを保持しようとしたが、表現差で署名が一致せずoperatorを一件も形成できなかった。

この二つは、表面差分を直接意味単位へ昇格させる経路の両端である。

## 仮説

> 日本語断片そのものではなく、複数エピソード間である部分を交換したとき、応答側でも対応部分だけが一貫して交換されるなら、その交換同値類を潜在束縛として採用できる。

学習器には生のprompt-response対だけを与えた。能力名、問題名、正解スロット、辞書、検索コーパス、外部LLMは与えていない。保持対象は、入力側の交換と出力側の交換が同時に成立した疎な規則だけである。

## 反例設計

- 学習応答を循環シャッフルしたdecoyでも規則が形成されるか
- 未知語ではなく未知構文・複合制約・因果・長期参照へ移せるか
- 自由対話、指示遂行、読解、推論、計画、因果・反実仮想、自由記述、長期対話、継続学習を同一モデルで処理できるか
- データ量18 / 72 / 180、seed 1 / 7 / 19で能力が単調改善するか

9能力の実出力はいずれも `未解決の要求を構成できません。` となり、データ量を18から180へ増やしても自由日本語能力は改善しなかった。

## 構造的反証

交換閉包は、同じ表面枠の中で名前や物体が置換される制御例から疎な規則を形成できた。しかし、未知構文、複合制約、読解、推論、計画、因果、長期参照へ移らなかった。さらに、応答を循環シャッフルした無意味なデータからも少数ながら規則が形成された。

したがって、局所的に対応する文字列置換は、潜在的な対象・役割・因果変数を同定する十分条件ではない。表面テンプレート、例外語句、手動スロット、類義語辞書を追加して修繕せず、この方式を知能コアとして棄却する。

## 次の最大ボトルネック

次に必要なのは交換可能な文字片ではなく、**同じ潜在変数を仮定したときだけ、複数時点・複数視点・介入後の予測を同時に短く説明できる持続的な対象同一性**である。

次サイクルではprompt-responseの二列だけから規則を作らず、観測系列内で対象仮説を生成・分裂・統合し、その仮説を反実仮想介入と時間をまたぐ再同定で競わせる。自由文生成より先に、未知表現下で同一対象を保持できるかを反証する。
