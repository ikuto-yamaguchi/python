# Exchange Binding Closure 001

## 直近の失敗

PR #119は頻出する文字差分を意味イベントとして保存し、学習量とともにイベント数だけが増えた。PR #120は別文脈へ移植できる文字残差だけを保持しようとしたが、表現差で署名が一致せずoperatorを一件も形成できなかった。

この二つは、表面差分を直接意味単位へ昇格させる経路の両端である。

## 新しい仮説

> 日本語断片そのものではなく、複数エピソード間である部分を交換したとき、応答側でも対応部分だけが一貫して交換されるなら、その交換同値類を潜在束縛として採用できる。

学習器には生のprompt-response対だけを与える。能力名、問題名、正解スロット、辞書、検索コーパス、外部LLMは与えない。保持対象は、入力側の交換と出力側の交換が同時に成立した疎な規則だけである。

## 反例設計

- 学習応答を循環シャッフルしたdecoyでも規則が形成されるか
- 未知語ではなく未知構文・複合制約・因果・長期参照へ移せるか
- 自由対話、指示遂行、読解、推論、計画、因果・反実仮想、自由記述、長期対話、継続学習を同一モデルで処理できるか
- データ量18 / 72 / 180、seed 1 / 7 / 19で能力が単調改善するか

モデルサイズ、Peak RSS、学習時間、平均・p95推論時間、候補数、規則数、decoy規則数、平均・最大読み出し量、9能力の実出力をJSONへ保存する。
