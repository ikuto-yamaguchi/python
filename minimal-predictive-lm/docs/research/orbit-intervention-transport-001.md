# ORBIT-1: Intervention Transport

## RAVEL失敗の原因

990MB版は容量不足ではなく、保存単位が抽象概念でなかった。

- 279,365観測から278,939個のprogramが生じ、再利用率は約0.15%。
- macro再利用率は約0.04%。
- 教材を3,200件から32,000件へ増やしてもJMMLU正解数は増えなかった。
- 容量とデータの増加は指紋、残差、active readだけを増やした。

根因は、実体名・文面・偶然の値がprogram IDへ漏れたこと、受動的な一つの前後差分だけで機構を同定したこと、別世界へ移植して反証しなかったことにある。

## 新原理

> 概念とは似た観測の集まりではない。役割名、値、無関係状態、世界個体を変えても結果を予測できる介入操作の同値類である。

これを **mechanism orbit** と呼ぶ。候補操作は次を満たす場合だけ保持する。

1. 複数の独立世界で前状態と制御量から後状態を再構成する。
2. 実体名や役割順を変えても同じ効果を再現する。
3. 無関係状態を保存する。
4. 競合操作を区別する反実仮想で選択的に成立する。
5. 観測指紋を保存するより総記述量を削減する。

最初の実装は操作名別コードではなく、共通の疎な整数演算子を探索する。

```text
y = A x + B c + b
```

加算、代入、移送、交換、複写、鏡映は同じ係数探索から生成される。

## 偶然同値への棄権

`x=0,c=5,y=5` は `y=x+c` と `y=c` の両方に一致する。ORBITは一例で決めず、両者が異なる別世界を観測するまで棄権する。

## スケーリング仮説

観測数を `N`、orbit数を `K(N)` とする。未知世界への適用範囲が増えながら、次を満たす必要がある。

```text
K(N) = o(N)
```

推論量は総データ量ではなく、関連orbit候補数と証明深度に依存させる。

今回の反証実験は最大3,072遷移、未知表現の一度接地、役割反転、無関係状態、8%破損、深さ16合成、偶然同値への棄権を測る。

## 境界

これは高校生級知能ではない。整数状態と制御量はまだ外部から与えている。次は普通の日本語から実体・状態・制御量を自律誘導し、同じorbitが形成されるかを反証する。形成されなければORBITを棄却または根本改訂する。
