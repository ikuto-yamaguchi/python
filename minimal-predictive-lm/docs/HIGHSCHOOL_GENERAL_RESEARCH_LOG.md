# High-School General Intelligence Research Log

## Entry 000 — Strategy correction

The sequence after PR #67 over-optimized one bounded textbook graph: demonstratives, omitted subjects, sparse suffix lookup, contradiction rejection, relation cardinality, and incremental cardinality updates. These are valid engineering improvements but do not constitute an approach to high-school-level general intelligence.

### Decision

- Stop creating independent local-feature PRs.
- Maintain one persistent integration branch and one shared model.
- Measure aggregate score, minimum-axis score, untouched-domain transfer, free-form dialogue, continual regression, and efficiency every cycle.
- Reject changes that pass only a local synthetic gate.

### Current bottleneck

The learner cannot induce a reusable semantic and procedural representation from ordinary heterogeneous Japanese material. Existing mechanisms rely on generated grammars, repeated paraphrases, bounded graph schemas, learned surface templates, or task-specific evaluation harnesses.

### Next falsifiable hypothesis

A shared predictive episode representation can jointly encode text spans, entities, quantities, relations, events, goals, evidence, and state transitions as sparse typed slots learned from compression gain rather than supplied task schemas. The first integrated experiment must compare this shared representation against the existing specialist composition on untouched Japanese reading, arithmetic verification, causal prediction, planning, and dialogue.
