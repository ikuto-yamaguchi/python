# Integrated acceptance checklist

A research cycle is complete only when all items below are answered.

- [ ] One shared serialized model was used for all axes.
- [ ] The model received no task or domain name.
- [ ] The frozen integrated data were not inspected or edited after evaluation began.
- [ ] Aggregate score improved.
- [ ] Minimum-axis score improved.
- [ ] No axis regressed more than two percentage points.
- [ ] Untouched wording improved.
- [ ] Untouched domain improved.
- [ ] Continual-learning regression stayed below five percent.
- [ ] Free-form explanations preserved evidence and proof.
- [ ] Unknown inputs were evaluated for both coverage and selective accuracy.
- [ ] Model bytes, peak RSS, candidates, reads, operations, training time, and inference latency were reported.
- [ ] No example-specific words, suffixes, task branches, or specialist router were added.
- [ ] The result is explicitly labelled below high-school level unless every cross-domain and dialogue threshold passes.

A local feature test cannot substitute for this checklist.
