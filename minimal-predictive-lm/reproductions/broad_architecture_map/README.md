# Broad architecture reproduction map

PR #116 以降の独自機構連作を止め、既存の主要系列を同じ条件で比較するための再現基盤です。

## 比較対象

- GRU
- 小型 causal Transformer
- 選択的ゲート付き単純SSM
- DeltaNet型の誤差書き込みメモリ
- RWKV-7型の減衰・delta補正付き行列状態

これは各公式実装の完全再現ではありません。構造上の中心更新を同じ語彙・幅・データ生成器・最適化器で比較するスクリーニングです。論文性能を主張しません。

## 評価

- 上書き記憶
- 複数照会
- modulo 10 の累積状態
- 学習量 128 / 512
- seed 1 / 7
- 通常長 depth=5
- 長さ外挿 depth=20
- モデルサイズ、Peak RSS、学習時間、token latency、候補数、状態読み出し量

## 評価バグと破棄結果

最初の実行では `回答` の1トークン手前を採点し、GRU等が固定語 `回答` を予測して100%に見える評価バグがありました。これは偽成功なので全結果を破棄しました。

修正後は `回答` トークン位置の次トークン、すなわち実際の色・数値だけを採点します。

## 結論

一律1 epoch・最大512例では全方式がほぼ失敗し、構造差より学習不足と評価条件が支配的でした。したがって、この結果から「GRUが最良」「RWKVが劣る」等は主張しません。

重大な進展は、狭い独自機構の追加ではなく、複数系列を同一ゲートで反証できる基盤と、偽成功を検出する評価監査を作ったことです。
