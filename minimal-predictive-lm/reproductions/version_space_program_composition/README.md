# Version-Space Program Composition

## 直近失敗

PR #138 の Reversible Episodic Binding は、episode 内に観測済みの未知表面値を可逆参照できましたが、値変換、変換合成、未観測値生成、計画、自由日本語は扱えませんでした。

## 仮説

操作名の表面文字列を意味として固定せず、episode 内の入出力例から各操作の候補関数集合を誘導します。複数操作を合成した後、すべての整合的候補プログラムが同じ出力へ到達した場合だけ回答し、候補が割れる場合は棄権します。

この原理は以下を狙います。

- 操作名や値を長期モデルへ保存しない
- 未知表面名でも episode 内の実例から意味を獲得する
- 固定長ではない操作列を合成する
- 証拠不足時に恣意的なプログラムを選ばない

Transformer、ニューラルネットワーク、問題別分類器、RAG、外部 LLM、完成回答記憶は使用しません。

## 実験

- 学習量: 32 / 128 / 512 episode
- seed: 1 / 7 / 19
- 1段 / 2段 / 4段合成
- 操作名・値の全面 rename
- 部分観測による曖昧性
- 一つの入出力例だけが意味的に誤ったが内部的には整合する反例
- 文脈依存の操作を単一関数として見せる反例
- 9系列の自由日本語統合ゲート
- モデルサイズ、Peak RSS、学習時間、推論時間、候補数、読み出し量

## 支持された部分

- episode 内の例だけから未知操作名の関数を誘導できる
- 可逆な表面束縛上で2段・4段の未見合成を実行できる
- 証拠不足でも、候補プログラム全体が同じ答えへ収束する場合だけ回答できる
- 候補が割れる部分観測の約72.9%で棄権できる

## 構造的反証

内部的に一貫した入出力例が与えられると、その操作が本来の意味と違っていても検出できません。文脈依存の操作も、観測範囲で単一関数に見える限り受理します。

したがって、

> 入出力例に整合するプログラムを誘導できることと、そのプログラムが現実・言語上の正しい意味を持つことは別問題である。

と反証されました。

固定構文、4値有限領域、episode 内で完結した完全な実演へ依存しており、自由日本語理解・説明・計画・因果・継続学習へは接続していません。
