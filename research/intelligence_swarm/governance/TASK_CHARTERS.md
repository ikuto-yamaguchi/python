# Task Charters

## A — Semantic Identity Birth

問い: 何が同じ対象・変数・関係として再同定されるのか。

成果物: identity proposal、cross-form witness、選択的lesion、失敗反例。

禁止: semantic unitを文字位置・区間幅・局所差分として先に固定し、後段で意味化すること。

## B — Operation and Goal Birth

問い: 何が行われ、何を目指し、どの条件で成功するのか。

成果物: executable operation proposal、goal revision witness、失敗修正、Aへ返す必要identity条件。

禁止: 外部能力0のままMDL、grammar、圧縮率だけを最適化すること。

## C — Causal Grounding

問い: identityとoperationが介入、時間順序、non-target保存、反実仮想を説明するか。

成果物: discriminating intervention、prospective causal witness、A/Bへ返す反例。

禁止: 観測済みafter差分だけから因果unitを主張すること。

## D — Memory Eligibility and Re-identification

問い: 何を同じ経験として再同定できたとき、記憶対象と認めるのか。

成果物: memory eligibility criterion、取得と保持の分離、gate成立後のone-shot・干渉・忘却評価。

禁止: Semantic Identity Gate未達のままreplay、assembly、fast/slow memoryを本線化すること。

## E — Integration Governor

問い: どの仮説族を継続・凍結し、研究段階と系列配分をどう変えるべきか。

成果物: STATE、BACKLOG、HYPOTHESIS_FAMILIES、DECISIONS更新、stage/gate判定、共通benchmark。

禁止: E固有の局所機構を追加し、5本目の類似実験へ戻ること。

## 受け渡し

- A → B/C/D: 再利用可能identity proposalと反例
- B → C/D: executable operation、goal、失敗条件
- C → A/B/D: 介入による識別条件、causal witness
- D → A/B/C: 再同定・記憶資格・取得/保持失敗の診断
- A〜D → E: 外部能力測定、baseline差、根本前提、次のボトルネック
- E → A〜D: stage、凍結族、優先順位、必須反例
