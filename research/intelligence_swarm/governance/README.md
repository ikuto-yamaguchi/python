# Intelligence Swarm Governance

このディレクトリは、A〜E系列の個別実験より上位にある研究制度を管理する。

## 目的

- 反証を局所仮説の言い換えではなく、仮説族の凍結と研究段階の変更へ接続する。
- 内部構造形成と、未知条件での外部能力向上を明確に分離する。
- 各系列を手段別ではなく、未解決の問いと受け渡し責任で分担する。
- Semantic identity未成立のまま下流の記憶・圧縮・graph・energy最適化を続けない。

## 正本

- `RESEARCH_STAGES.md`: 現在段階と遷移gate
- `TASK_CHARTERS.md`: A〜Eの役割と受け渡し
- `PROGRESS_RULES.md`: 進歩、診断、反証、凍結の判定規則
- `HYPOTHESIS_FAMILIES.md`: 活動中・凍結済み仮説族
- `DECISIONS.jsonl`: 統合司令Eによる時系列意思決定

## 優先順位

1. 外部能力の成立
2. Correctとshuffle/randomの分離
3. 未知表現・別領域への転移
4. 選択的lesion・介入による因果証拠
5. 資源効率
6. 内部構造の簡潔さ

候補数削減、圧縮、graph形成、低rank性、収束、棄権増加だけでは進歩と呼ばない。
