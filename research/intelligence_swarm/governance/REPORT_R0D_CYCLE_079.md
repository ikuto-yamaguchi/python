# R0-D Cycle 079 — shuffle metric-scope audit

## Scope

R0 benchmark reproducibility/statistics/leakage auditing only. No memory, replay, fast weights, sleep, or forgetting mechanism was introduced.

## Finding

The core already bound `target_label_shuffle.pred_action` to the donor `gold_action` and `outcome_shuffle.pred_state_after` to the donor `gold_state_after`. However, both shuffle controls were still scored on both `action` and `prospective` metrics.

That left the complementary, non-bound output free to carry arbitrary or oracle-quality values:

- `target_label_shuffle.pred_state_after` could contaminate prospective statistics.
- `outcome_shuffle.pred_action` could contaminate action statistics.

A valid donor permutation therefore did not guarantee that every reported shuffle statistic was generated by the declared intervention.

## Fail-closed rule

- `target_label_shuffle` may report only `action`.
- `outcome_shuffle` may report only `prospective`.
- `random`, `language_blind`, `state_only`, and `correct` retain the normal reportable metric set.
- Unbound complementary metrics must not appear in cells, summaries, confidence intervals, minimum-cell gaps, paired randomization tests, cluster bootstrap intervals, or McNemar tests.

The score artifact records `shuffle_metric_scope_required=true` and the allowed metric set for each shuffle method.

## Classification

Until the core patch and focused regression succeed on the canonical branch, R0 remains `initial_reproduction_failure`. No public baseline reproduction or accepted resource/statistics bundle is claimed.
