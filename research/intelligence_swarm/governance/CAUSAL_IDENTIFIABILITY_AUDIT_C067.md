## Decision-relevant question

C066 rejected AP001 because the proposed unique anchor signature either supplied target identity or could not be bound to an unknown target. The remaining positive direction was to find a genuinely joint observation law that could align language and causal systems without target-indexed pairing.

C067 audits whether identifiability from **unaligned multimodal distributions** already provides such a route.

## Primary prior art

Timilsina, Shrestha, and Fu, **“Identifiable Shared Component Analysis of Unpaired Multimodal Mixtures”**, NeurIPS 2024.

Primary sources:

- NeurIPS proceedings: https://proceedings.neurips.cc/paper_files/paper/2024/hash/e6c967a0e4168df9614a81ed4195ba78-Abstract-Conference.html
- OpenReview: https://openreview.net/forum?id=ivCX2cjwcT
- arXiv: https://arxiv.org/abs/2409.19422
- Official code: https://github.com/XiaoFuLab/Shared-Component-Analysis
- Audited official-code commit: `d62d2940f6d4ac471fe871614730d69f1b4f4ea5`

The paper studies two or more modalities generated by linear mixtures of shared and modality-private components. Unlike aligned CCA-style settings, the cross-modal samples need not be paired. It proposes distribution-divergence minimization and gives sufficient conditions under which the shared component is identifiable up to the paper's declared ambiguities.

This is directly relevant to C066 because it demonstrates that sample-level pairing is not always necessary: structural restrictions on the mixtures and source distributions can make a shared latent block identifiable from unpaired modality distributions.

## Assumption, observation, and guarantee comparison

### Observations in unaligned SCA

For modality `r`, observations satisfy a linear mixture model of the form

`x^(r) = A^(r) [c; p^(r)]`,

where:

- `c` is a shared latent component;
- `p^(r)` is modality-private;
- samples across modalities are not paired by entity;
- only the marginal sample sets from each modality are observed.

The method matches the distributions of projected modality representations and imposes whitening-type constraints. The paper removes density-preserving ambiguities under explicit distributional or structural conditions.

### Guarantee

Under the paper's assumptions, the shared latent representation can be recovered up to its declared linear ambiguity. The result identifies a modality-invariant latent block, not an arbitrary sample-level correspondence between individual observations from different modalities.

### RQ-001 observations and target

RQ-001 requires recovery of:

- an unknown raw-language equivalence relation `Q`;
- an unknown latent intervention-target partition `P`;
- a denotation relation `d` linking classes in `Q` to blocks in `P`.

The central missing object is the cross-system correspondence, including whether two language forms denote the same target and which target block a recovered language class denotes.

## What this prior work removes from the novelty candidate

The following cannot be claimed as new in isolation:

- identifying a shared representation from unpaired modalities;
- aligning modality distributions without entity-level paired samples;
- using distribution divergence to recover modality-invariant components;
- recovering shared and private linear latent blocks under structural assumptions;
- using weak structural constraints to remove density-preserving transforms;
- claiming that lack of paired language/causal samples alone makes cross-system identification impossible.

The paper establishes an important positive boundary: **unpaired observations can identify a shared latent block when the modalities are generated from the same latent component under restrictive but explicit assumptions.**

## Why this does not yet identify denotation

A shared latent component is not automatically the denotation map.

The theorem assumes that both modalities contain the same shared random variable `c`. In an RQ-001 interpretation, this would require language observations and causal observations to already be generated from one common latent variable with a specified factorization.

That assumption may be legitimate only if it can be stated without using:

- target IDs;
- parser semantic slots;
- paired utterance–target examples;
- simulator object names;
- reward or evaluator labels encoding the target;
- a generative construction that directly reads `d`.

Otherwise, the disputed cross-system relation has merely been moved into the assumption that a particular latent component is shared.

Further, unpaired distribution matching identifies common structure in distributions. It does not generally recover which individual language class corresponds to which individual intervention target.

## Identifiability counterexample: same unpaired marginals, different denotation coupling

Let the recovered language quotient be `Q={q_1,q_2}` and the recovered causal target quotient be `P={p_1,p_2}`.

Assume both sides expose the same binary shared latent marginal:

- language-side shared value `C_L` is uniform on `{0,1}`;
- causal-side shared value `C_P` is uniform on `{0,1}`.

Consider two models.

### Model A

- `q_1` corresponds to shared value `0` and denotes `p_1`;
- `q_2` corresponds to shared value `1` and denotes `p_2`.

### Model B

- the language-side and causal-side marginal distributions are unchanged;
- `q_1` denotes `p_2`;
- `q_2` denotes `p_1`.

With no paired cross-system sample and no asymmetric external consequence that links one language class to one target block, both models preserve:

- the complete language marginal distribution;
- the complete causal/intervention marginal distribution;
- the shared-component distribution in each modality;
- all distribution-divergence objectives;
- whitening constraints;
- recovered shared subspaces;
- modality-private component distributions;
- any metric invariant to the common component relabeling.

Yet `d_A != d_B`.

This is not contradicted by unaligned SCA: its theorem identifies a shared component up to declared ambiguity under a generative common-source model. It does not infer an arbitrary semantic coupling between separately recovered discrete quotients when the coupling is absent from the observed joint law.

## Stronger coupling counterexample: shared content without semantic ontology

Suppose both language and causal observations genuinely depend on the same continuous shared source `c`, and unaligned SCA recovers `c` up to an invertible linear transform.

Two semantic ontologies can still agree on the entire continuous shared representation while differing in their partitions:

- Ontology A partitions `c` at threshold `0`;
- Ontology B partitions `c` at a different threshold or uses a different measurable partition;
- language encoders, target decoders, and downstream interfaces are changed consistently.

If the observations and objectives depend only on the continuous `c`, both ontologies can preserve the same recovered shared subspace and all modality distributions while inducing different `Q`, `P`, and `d`.

Therefore shared-source identifiability is weaker than semantic-partition identifiability unless the semantic partition itself is tied to an independently observable law.

## Merge/split consequence

Unpaired distribution matching also does not by itself resolve whether two observationally identical modes should be:

- merged as one semantic target with two synonymous language classes; or
- split as two semantic targets whose induced modality distributions are identical.

A common latent distribution can be identifiable while a finer ontology remains non-identifiable.

## Prior-art matrix refinement

| Line of work | Pairing requirement | Main guarantee | Residual issue for RQ-001 |
|---|---|---|---|
| Paired multi-view nonlinear ICA | paired views of a common latent entity | common latent recovery under nonlinear multi-view assumptions | pairing/common-source construction may already encode correspondence; denotation and ontology remain free |
| Unaligned Shared Component Analysis | no cross-modal sample pairing; linear shared/private mixtures | shared component recovery under distributional/structural assumptions | identifies a common latent block, not arbitrary class-to-target denotation or merge/split ontology |
| Unknown-target CRL | observational/interventional environments | causal coordinates or intervention targets up to declared transformations | language equivalence and external meaning remain free |
| Language dynamics models | text sequences or language-internal relations | predictive or language-internal quotient | causal target correspondence remains free |
| AP001 | target-indexed unique signature observed for each language class | exact lookup of the denotation | supplies target identity and is only an oracle control |

## Decision

**NARROWED BEYOND IDENTIFIABLE UNPAIRED SHARED-COMPONENT RECOVERY — NOT ADOPTED.**

The candidate RQ is narrowed to:

> After separately recovering the finest language and causal quotients, can an empirically observable joint law identify their denotation without paired target labels, target-indexed channels, or a generative assumption that directly installs the disputed correspondence? Any positive theorem must distinguish recovery of a shared latent distribution from recovery of the class-level coupling, semantic partitions, and merge/split ontology.

## Decision progress

C067 changes the positive-search boundary in two ways:

1. It rejects the overly strong claim that lack of paired samples alone blocks identification; unpaired shared-component identification is established prior art under explicit assumptions.
2. It shows that distribution-level shared-component recovery is still insufficient for RQ-001 because the class-level coupling and ontology can vary while all unpaired modality laws remain fixed.

The next admissible positive route must provide an observable **cross-system dependence law**, not merely matching marginals or asserting a common latent source. Alternatively, a public unaligned-SCA baseline can be reproduced as a negative-control boundary before any architecture proposal.
