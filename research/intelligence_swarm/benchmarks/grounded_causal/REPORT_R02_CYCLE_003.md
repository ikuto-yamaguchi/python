## Corrected implementation assumption

The previous smoke implementation predicted the low-level action from the
language-derived latent alone. That is unsuitable for sequential RTFM because a
single task instruction permits different navigation actions at different
locations. Cycle 003 changes the action decoder to `p(a | state, latent)` while
retaining the two-stage environment-first structure:

1. infer a latent transition from `(state, next_state)`;
2. train a decoder for `next_state` and action conditioned on `(state, latent)`;
3. freeze that decoder and map raw task/wiki tokens to the latent;
4. compare with an end-to-end instruction model with the exact same inference
   parameter budget;
5. separately train a state-only control.

This is a correction required for faithful sequential use, not a novelty claim.

## Invalid metrics and non-claims

The exported 414-dimensional state vector mixes continuous/binary values with
categorical token IDs from observation fields. Consequently, the current raw
scalar next-state MSE is not interpretable and is explicitly invalidated.
Field-aware categorical losses or normalized typed state components are required
before next-state prediction can be compared.

The following are also not measured:

- online RTFM task success for the R0.2 models;
- held-out entity transfer;
- held-out dynamics/mechanism transfer;
- held-out language-form transfer.

The recurrent checkpoint supplying trajectory actions was trained for only 2,048
frames and achieved no positive matched-evaluation result. The present dataset is
therefore suitable for pipeline and assumption auditing, not for final capability
comparison.

## Decision

Classification:

`public_trajectory_offline_negative_diagnostic_not_r02_reproduction`

R0.2 is **not reproduced** and no capability progress is recognized. The result
falsifies the claim that this current public trajectory/export configuration
already provides language-dependent instruction-following evidence.

## Next minimum valid experiment

1. Replace raw flattened-state MSE with typed field-aware prediction losses.
2. Capture trajectories from a substantially trained or successful public policy,
   or use demonstrations whose action labels are not dominated by an undertrained
   policy.
3. Define true entity, dynamics/mechanism and language-form held-out splits.
4. Deploy environment-first, matched end-to-end and state-only models online in
   RTFM to measure task success.
5. Require language blind and within-environment language shuffle to reduce held-out
   external capability before treating the language stage as operational.
