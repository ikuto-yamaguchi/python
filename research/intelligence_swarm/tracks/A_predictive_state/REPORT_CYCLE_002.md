# 系列A Cycle 002 — Active Distinguishing Predictive States

## 仮説

受動的な未来分布だけで履歴を圧縮せず、競合する潜在状態を最も分離する確認発話を情報利得で選べば、必要なidentity差を保持しながら少数状態で推論できる。

|---|---|---|
| B | 階層可逆MDL parse | 境界・文法候補ではなく、既存状態候補を分離する行為選択 |

| E | 学習factorによる制約緩和 | 候補energyの収束ではなく、追加観測を能動取得 |

継承した知見は、A Cycle 001の「受動予測圧縮は必要差を消す」、C Cycle 002の「episode identityを別チャネルへ保護する」、E Cycle 002の「同型候補へ重みを足しても識別できない」です。

## 実装

16個以下の潜在状態候補を保持し、観測済みcontinuation partitionから、期待除去候補数が最大の確認を選択する最小プローブを実装した。比較は、欠損値を事前値で補うpassive baseline、確認を禁止したactive-state ablation、確認を許可するactive方式である。

## 支持された部分

受動的に状態を一つへ潰すより、複数候補を保持して情報利得の高い追加観測を1回取得する方が、有限状態診断では大幅に高い同定率を示した。予測状態は「圧縮表現」だけでなく「次に何を観測すべきかを決める仮説集合」として扱う価値がある。

## 決定的な反証・監査

この実装は汎用知能原理としては棄却する。

1. 色・場所・値集合をコードに与えており、手書きontologyを含む。生の日本語から因子を生成していない。
2. 確認候補 q0/q1 も既知因子軸から作っており、自由日本語から確認発話を創発していない。
3. 正しい環境応答を実験器が直接返しており、実対話で相手の曖昧な返答を理解していない。
4. 自由対話、指示遂行、読解、推論、計画、因果・反実仮想、自由記述、長期対話、継続学習の統合ゲートは未達。
5. active_no_queryがpassiveより低いため、候補集合を持つだけでは改善せず、成功は追加教師信号に依存する。

したがって支持できるのは、潜在因子が既に存在する場合の能動識別原理だけである。

## 系列A固有の進展

「同じ未来を予測する履歴をまとめる」から一段進み、状態表現の価値を `予測精度` ではなく `競合状態を分離する観測を提案できるか` でも測るべきことを実測した。一方、その確認軸を手書きせず生の日本語から生成する問題が最大ボトルネックとして残った。

## 次の仮説

**Open-Set Query Proposal from Predictive Disagreement**

固定q0/q1を廃止し、Bの複数可逆parse、Cの対照介入、Dの複数view binding、Eの異構造factor graph候補を入力として、候補世界が異なるcontinuationを予測する最小発話区間を確認候補として生成する。確認は既存文の検索ではなく、候補間で異なる可逆残差を組み合わせて生成する。

成功条件は、未知構文・未知対象でも確認候補を生成し、確認後の状態同定、言い換え、confound棄権を同時改善し、手書き因子軸を完全に除去すること。
