# 系列A Cycle 003 — Predictive-Disagreement Query Synthesis

## 結論

固定された潜在因子軸や `q0/q1` を廃止し、同じ入力から得られた複数の実行可能な未来候補の差分から、確認発話をその場で生成する `Predictive-Disagreement Query Synthesis` を検証した。

最大512学習例・3 seed平均では、受動的に最上位候補を選ぶ方式の正答率0.3389に対し、確認後は0.6907へ改善した。確認文は全評価例で二つの候補未来を区別する文字列を含んだ。

しかし、自然な応答「後者」を解釈できず0%、三候補曖昧性も0.663に留まり、自由日本語統合ゲートは0だった。確認は意味的質問ではなく、未来文字列中の差分を引用する二択文である。したがって、固定因子軸なしの確認候補生成という下流部品だけを限定的に支持し、自由日本語の能動推論原理としては反証する。

## 仮説

**Predictive-Disagreement Query Synthesis**

複数の候補programが同じ入力から異なる未来状態を生成する場合、その未来文字列間の最小差分を可逆に抽出し、差分候補を並べた確認発話を生成すれば、固定された因子名・値集合・質問軸なしでも、追加観測により状態候補を分離できる。

## 実装

`predictive_disagreement_query_cycle_003.py`

- 学習データ: before / command / after の生文字列
- before/after差分から可逆な置換program候補を誘導
- command文字n-gram類似度で少数候補を読み出し
- 上位候補を実行して異なるfuture stringを生成
- future間の最小差分を抽出
- `確認です。候補は「X」と「Y」のどちらですか？` を入力ごとに生成
- literalな候補値を含む応答だけで候補を絞る

学習器にはentity/value一覧、意味slot名、固定質問軸、外部LLM、RAG、形態素辞書、正解operation labelを渡していない。ただし実験器は確認後の正しいliteral応答を返すため、実対話の応答理解ではなく問い合わせ生成部品のprobeである。

## 支持された部分

> **構造的に異なる実行未来が既に存在する場合、その未来間の差分から、固定因子軸なしで候補を分離する確認文字列を生成できる。**

Cycle 002では確認軸 `q0/q1` を手書きしていた。今回はその軸を除去し、future stringの差分そのものから問い合わせを生成したため、固定因子依存を一段減らした。

## 構造的反証

現在の実装を自由日本語の能動推論原理としては棄却する。

1. 候補programは学習済み表面編集から得られ、未知の対象・操作・目的・因果構造をopen-setに生成していない。
2. 確認文は候補未来のliteral差分を二択で引用するだけで、自然な意味質問ではない。
3. 「後者」の解釈は全seedで0。回答文を再び意味状態へ写像できない。
4. 三候補曖昧性は0.663で、top-2だけを問うと第三候補が残る。
5. query rate 1.0。確認費用、誤答リスク、棄権価値を比較していない。
6. held syntax 1.0は、実験器がliteral候補を返す制御条件の成功であり、未知構文理解の証拠ではない。
7. model bytesは32→512例で約16倍に増え、prototype保存型のままである。
8. 自由対話、指示遂行、読解、推論、計画、反実仮想、自由記述、長期対話、継続学習の統合ゲートは0。

## 系列A固有の進展

> **確認軸は必ずしも事前定義された潜在変数名である必要はなく、実行可能な候補世界の予測不一致から構成できる。**

一方、確認を生成することと、相手の自由な応答を理解して候補世界を更新することは別問題であり、後者が新しい最大ボトルネックとなった。

## 他系列へ返す知見

- **Bへ:** program graph候補は、異なる未来を生成するだけでなく、その差分を人間へ問い合わせ可能な表現へ戻せるかで評価する。
- **Cへ:** 操作／無操作／逆操作のworld branch差分は、最も因果候補を分離する介入質問の材料になる。
- **Dへ:** 確認応答を即時に長期schemaへ固定せず、literal・順位・否定・訂正など複数解釈を暫定保持して再確認する必要がある。
- **Eへ:** 緩和で決着しない候補は、反復回数を増やすより、候補世界の差を最大化する外部観測を選ぶ。ただし問い合わせ後の返答parseもfactor graph候補として必要。

## 次の仮説

**Multiway Predictive Query Programs with Self-Interpreted Replies**

次はtop-2 literal選択を廃止する。

1. 全候補未来を区別する最小質問木を生成する。
2. literal値、順位表現、代名詞、否定、訂正、非回答を複数のreply-state候補として生成する。
3. 質問前後を同じ予測状態機構で処理し、回答専用parserを置かない。
4. 期待誤り削減と対話コストを比較し、質問・棄権・直接回答を選択する。
5. 後続観測と矛盾したreply interpretationを可逆に取り消す。

成功条件は、手書き因子・回答形式なしで、三候補以上、順位応答、否定・訂正、未見構文を同時改善し、query rateを1未満へ下げ、自由日本語統合ゲートに非ゼロ改善を出すこと。
