# 系列A Cycle 005 — Self-Predicting Reply-State Programs without Outcome Leakage

## 目的

Cycle 004では、曖昧な返答解釈を後続観測で改訂できたが、後続観測に最終正答値そのものが含まれていた。そのため、返答理解ではなく正答漏洩による遅延訂正だった。

本サイクルでは最終値を一切含まない汎用的な承認・否定フィードバックだけを使い、予測状態候補を可逆に改訂できるか検証した。

## 他系列との重複監査

| 系列 | 最新の中心機構 | 系列Aで今回扱う差分 |
|---|---|---|
| B | operation node / surface decoder 分離とMDL圧縮 | operation encoderではなく、対話中の返答候補改訂 |
| C | identity分離event programとworld branch | 因果event実行ではなく、候補解釈への外部フィードバック統合 |
| D | episode groupingと低速記憶統合 | 長期記憶ではなく、即時の短期予測状態更新 |
| E | role構造付き候補graphとアトラクタ | 内部energy収束ではなく、外部の承認・否定による状態遷移 |

系列Eの「候補が異なる未来を生成しなければ識別不能」、系列Dの「曖昧候補を不可逆固定しない」という知見を継承した。

## 仮説

候補値そのものを後続観測へ出さなくても、モデルが提案した解釈に対する承認・否定という1 bitの対話フィードバックを予測状態更新へ組み込めば、二候補の曖昧性を解消できる。

ただし三候補以上では1 bitだけでは不十分であり、候補集合の構造に応じた追加問い合わせが必要になると予測した。

## 実装

- 返答文を候補値で匿名化し、文字2/3-gramから相対rank programを誘導
- exact episode prototypeではなく、匿名化済み返答patternを重複排除して保持
- 解釈候補の最上位を一旦提案
- 正答値を含まない承認・否定発話を別の局所programで解釈
- 承認なら候補維持、否定なら二候補の場合のみ反対候補へ改訂
- 情報を持たない一般応答では確信せず棄権

外部LLM、RAG、形態素解析、意味slot名、固定ontology、最終状態値を含む後続観測は使用していない。

## 実験条件

- 学習量: 32 / 128 / 512 episode
- seed: 1 / 7 / 19
- 各split: 160件
- 直接値、順位表現、否定、訂正、未学習返答形式
- 三候補曖昧性
- 学習済み承認・否定表現
- 未学習承認・否定表現
- 情報を持たない後続発話
- モデルサイズ、推論時間、pattern数、候補読み出し量、Peak RSS

## 限定的に支持された部分

正答値を含む観測を使わず、承認・否定だけで二候補の状態を改訂できた。Cycle 004の結果漏洩を除いても、次の下流原理は成立した。

> 予測状態候補を一度確定せず、提案した解釈に対する一般的な承認・否定を状態遷移として扱うと、二候補の曖昧性を可逆に解消できる。

匿名patternの重複排除により、学習量32→512の16倍に対しmodel bytesは1,045→1,251に留まり、前サイクルの線形prototype増加は回避した。

## 決定的な反証

### 1. 二候補だから成立しただけ

否定1 bitで反対候補を一意に決められるのは二候補の場合だけである。三候補ではfeedback後も0.1833から改善しなかった。

### 2. 承認・否定の意味は閉集合

未学習feedback表現が成功したのは、文字n-gramが既知の承認・否定表現へ近かったためであり、一般的な対話行為を創発したわけではない。

### 3. 情報なしfeedbackへの校正が不十分

情報を持たない発話への棄権率は約0.61–0.68であり、3割以上は誤って承認・否定として解釈した。対話行為境界は未成立である。

### 4. 元の返答理解は改善していない

否定返答の即時精度は0のままであり、モデル自身が「Aではない方」を理解したのではない。誤った提案を外部の拒否で修正しただけである。

### 5. 自由日本語統合能力は0

自由対話、読解、指示遂行、計画、因果、反実仮想、自由記述、長期対話、継続学習には接続していない。

## 系列A固有の進展

能動対話を次の4段階へ分離できた。

1. 候補世界を形成する
2. 候補を分離する質問を生成する
3. 返答から候補を即時更新する
4. 更新結果への承認・否定で可逆に再改訂する

Cycle 005で成立したのは第4段階の最小二値版である。重要な結論は次である。

> 結果値の直接漏洩なしでも対話feedbackは予測状態を修正できるが、候補数に応じた情報量と、feedback自体のopen-set意味理解がなければ一般化しない。

## 他系列へ返す知見

- B: operation候補を利用者へ提示する場合、承認・否定で可逆更新できるが、三候補以上では質問木が必要。
- C: 因果候補への介入確認は二値拒否だけでは複数原因を識別できず、候補分割に応じた追加介入が必要。
- D: 曖昧なmemory groupingを低速統合する前に、一般feedbackによる修正履歴をfast stateへ保持すべき。
- E: flat energyで決着しない候補へ外部feedbackを使えるが、feedbackが与えるbit数より候補entropyが大きい場合は収束不能。

## 次の仮説

**Entropy-Matched Multi-Turn Predictive Repair Programs**

候補集合のentropyに応じ、必要な情報量を満たすまで複数ターンの質問・承認・否定を構成する。

次サイクルでは:

1. 二候補固定を廃止し、2–8候補を扱う
2. 候補をほぼ二分する質問木を予測差分から生成
3. yes/no、順位、除外、訂正、非回答を同じ状態遷移として扱う
4. 情報なしfeedbackで誤更新しない校正を導入
5. 期待情報利得と対話コストで質問停止を決める
6. 候補entropyと取得bit数の整合を測定

成功条件は、候補数が増えても即時＋対話後精度が改善し、質問回数が理論的な `ceil(log2 K)` 付近に収まり、closed feedback表現への依存を減らすことである。
