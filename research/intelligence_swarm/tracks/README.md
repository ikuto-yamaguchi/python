# Track Layout

## Active question-based tracks

- `A_semantic_identity/`: 意味単位・対象同一性・変数創発
- `B_operation_goal/`: 操作・目的・実行可能プログラム創発
- `C_causal_grounding/`: 因果接地・識別可能性・反実仮想
- `D_memory_eligibility/`: 記憶資格・再同定・継続学習
- 統合司令Eの成果は `../governance/` に保存する。

## Legacy evidence

次の旧ディレクトリは削除・改名せず、反証証拠として保持する。

- `A_predictive_state/`
- `B_compression_symbols/`
- `C_causal_world/`
- `D_memory_learning/`
- `E_constraint_relaxation/`

旧系列の実験を新系列へコピーして新規性を装ってはならない。再利用する場合は、元PR、根本前提、以前の支配的失敗、新しい前提差を明記する。
