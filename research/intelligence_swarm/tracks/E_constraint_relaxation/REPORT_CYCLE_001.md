# 系列E Cycle 001 — Joint Sparse Constraint Relaxation

## 結論

`Joint Sparse Constraint Relaxation` は、複数の候補編集プログラムを一括で保持し、局所整合性エネルギーを反復的に下げることで、単発の最近傍選択より2段計画を改善した。512例・3 seed平均で、greedy 0.2458 に対し relaxation 0.8208 だった。

ただし、候補生成は人工的な定型日本語に対する文字編集プログラムであり、対象・操作・目的・因果の意味を自律獲得したわけではない。自由日本語、未知構文、長文、入れ子、反実仮想、自由生成は未達であり、汎用知能原理としては未成立である。

## 他系列との重複監査

| 系列 | 現在の中心機構 | 今回との差 |
|---|---|---|
| A | 予測誤差・再帰状態・能動推論 | 次状態予測器ではなく候補解釈の同時制約緩和 |
| B | MDL残差・記号創発・潜在プログラム | 圧縮目的ではなく複数候補間の全体整合性。複数候補保持を継承 |
| C | 介入安定イベント・因果グラフ | 介入不変性ではなく、計画中の候補編集が状態表現を壊さない制約。抽象操作とepisode identity分離の必要性を継承 |
| D | 高速束縛・低速schema・継続学習 | 記憶検索ではなく、その場の候補選択と収束。単発検索では意味統合にならない知見を継承 |

## 仮説

生の入力に対して複数の候補プログラムを同時保持し、各候補の局所適合度だけでなく、複数段の適用後も状態表現の不変部分を壊さないこと、無効な無変化を避けること、編集量が過大でないことをエネルギーとして統合すれば、一方向の最近傍分類より整合した計画状態へ収束できる。

### 単なるHopfield記憶との差

- 保存済みパターンへの単純なアトラクタ復元ではない。
- 各入力ごとに複数の編集プログラム候補を生成する。
- 候補の組合せを複数段計画全体で評価する。
- 収束対象は固定パターンではなく、入力ごとに変わる候補組合せである。

## 実装

学習例の `before / command / after` から、意味slotを与えず、可逆な文字残差編集を候補プログラムとして保存した。推論ではcommandの文字3-gram類似度から上位6候補を生成し、以下のエネルギーを座標降下で最小化した。

- commandとの非類似度
- 状態が変化しない候補への罰則
- 文字数変化が過大な候補への罰則
- 状態の不変フレームを壊す候補への罰則

停止条件は、1 sweepで候補が変わらない、エネルギー差が1e-9未満、最大12反復のいずれかである。

## 実験

- 学習規模: 32 / 128 / 512
- seed: 1 / 7 / 19
- baseline: 各commandで最類似候補を即時選択
- relaxation: 各段6候補を同時保持し座標降下
- 2段の場所変更計画
- 未知名称rename
- 命令言い換え
- 矛盾する連続命令での低margin棄権
- モデルサイズ、Peak RSS、学習・推論時間、反復回数、活性候補数

### 最大規模の資源

- serialized model: 平均 120,788 bytes
- Peak RSS: 298,156 KiB（Python runtime込み）
- 学習時間: 0.00611秒
- 2段計画推論: 6.57 ms/query
- 平均反復: 1.64
- 活性候補: 12

1GB未満というモデルサイズ条件は満たすが、Python runtime込みRSSは弱いスマートフォン条件を検証していない。ネイティブ実装なら候補12個・平均1.64 sweepなので計算量は小さいが、実機測定が必要である。

## 支持された部分

- 候補を即決せず、複数段の状態整合性を含めて同時に選ぶと、2段計画の表面実行精度が改善した。
- 収束は平均2 sweep未満で、候補数を疎に制限すれば動的計算深度は小さい。
- best解と1-flip代替解のmarginは、矛盾入力の一部を棄権させる信号になった。

## 構造的反証

1. 候補生成が学習済み文字編集に依存し、未知の操作や新しい文法を生成できない。
2. 状態フレーム文字列を壊さないという制約は、意味的整合性ではなく表面形式の保護である。
3. 言い換えは512例でも0.5667に留まり、自由日本語へ一般化しない。
4. rename成功は引用符付き名称が状態中で保持される人工構造によるところが大きい。
5. 矛盾時棄権は0.7917だが、因果矛盾を理解したのではなく、候補間marginが縮小しただけである。
6. 対象・変数・目的・因果候補の自律生成、自由対話、読解、反実仮想、自由記述、長期対話、継続学習は未達。

したがって、現在の実装を日本語汎用知能としては棄却し、`複数候補を疎に保持し、局所適合度ではなく全体整合性で反復選択する` という部分原理だけを保持する。

## 他系列へ返す知見

- A: 予測状態候補を単一に早期確定せず、複数仮説を少数保持し、将来整合性で緩和する価値がある。
- B: MDLで生成した複数の潜在構文・プログラムを、記述長だけでなく複数段実行後の整合性エネルギーで再順位付けできる。
- C: 介入イベント候補は、各イベント単体の安定性だけでなく、複数イベント合成後の状態整合性で監査すべき。
- D: 高速記憶から一件を検索する前に、少数候補を推論状態へ注入し、他制約と同時に収束させる必要がある。

## 次仮説

`Learned Constraint Factor Induction` を次に検証する。

固定した「状態フレームを壊さない」罰則を廃止し、系列Bの可逆MDL分解と系列Cの介入差分から、どの部分がepisode identity、関係、操作、不変量として振る舞うかを自己教師ありでfactor化する。各factorの局所エネルギーを、正例ラベルではなく、将来予測改善、介入再現性、可逆再構成、圧縮利得の合意から学習する。未知構文でもfactor候補を入力ごとに生成し、候補崩壊・局所最適・発散を独立に測定する。
