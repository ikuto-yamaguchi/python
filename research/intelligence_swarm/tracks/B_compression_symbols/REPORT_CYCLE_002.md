# 系列B Cycle 002: Hierarchical Reversible MDL Frames

## 目的

Cycle 001 の corpus-global MDL residual anchor は未知名称 span を生成できたが、言い換え完全一致は全 seed で 0 だった。今回は単一 substring の採点を延長せず、複数の可逆な上位フレームを誘導・競合させれば、未知表面・語順変更・入れ子・主語省略へ一般化できるかを検証した。

## 他系列との重複表

| 系列 | 最新中心機構 | 成功 | 失敗・未解決 | 本系列との差 |
|---|---|---|---|---|
| A | 将来分布による予測等価状態 | 表現量・候補読出し・推論速度を削減 | identity と介入差を不可逆に消失 | 未来状態圧縮を使わず、可逆文法導出の説明長を比較 |
| C | 介入安定 residual event | 矛盾介入の棄権信号 | 表面編集座標と個体 identity が混在 | 介入意味を扱わず、抽象フレームと入力固有 gap の分離だけを検証 |
| D | structural rebinding memory | 一回提示・最新値上書き | answer span 依存、言い換え 0 | 記憶保存則ではなく、保存前の自己教師あり境界・階層構造誘導 |

実質重複する候補として、A型 future equivalence、C型 intervention equivalence、D型 fast binding、E型 coordinate relaxation は採用しなかった。

## 継承した知見

- B Cycle 001: 未知部分を直接辞書化せず、再利用可能な固定部分を圧縮し残差を入力上で生成する。
- A Cycle 001: 圧縮時に episode identity を不可逆に捨ててはいけない。
- C Cycle 001: 抽象操作と episode 固有表面を別チャネルに保持する。
- D Cycle 001: 抽象 schema は知識本体ではなく、新しい入力を束縛へ変換する生成器として評価する。
- E Cycle 001: 候補を早期に一つへ潰さず、少数候補を比較する。

## 新仮説

**Hierarchical Reversible MDL Frames**

1. 文字列コーパスから MDL 利得の高い literal anchor を誘導する。
2. 各文を anchor と residual gap の可逆列へ分解する。
3. 複数文の anchor skeleton 間で LCS を取り、上位フレーム候補を作る。
4. 推論時には入力ごとに複数フレームを整列し、gap 境界を新規生成する。
5. literal coverage、gap 数、フレーム複雑度から記述長を比較する。

予測: 単層 anchor より、語順変更・入れ子・主語省略で span F1 と完全一致が改善する。

反証条件: 言い換え・省略完全一致が 0 のまま、または改善が単層 anchor に対して微小で、データ増加でも構造的に伸びない。

## 実験

- 学習文: 90 / 360
- seed: 1 / 7 / 19
- 6系列の人工日本語指示（2変数、3変数入れ子、条件）
- 未知名称全面置換
- 未学習の言い換え・語順変更
- 主語省略
- 比較: Cycle 001 型単層 anchor residual
- 測定: span F1、完全一致、候補 parse 数、モデル bytes、学習・推論時間、Peak RSS

モデルは形態素解析、固定 slot、手書き ontology、外部 LLM、RAG、正解ラベル学習を使用しない。データ生成時の span は評価だけに使う。

## 判定

**部分部品として限定支持、一般的な記号創発仮説として反証。**

複数の上位フレームを保持することで、言い換え F1 は約 +0.0103、主語省略 F1 は約 +0.0083 改善した。しかし未知名称では単層方式を下回り、言い換え・省略の完全一致は全 seed で 0 のままだった。

失敗原因:

1. LCS は literal の共有順序しか抽象化せず、同義表現を同じ終端・操作へ束縛できない。
2. MDL は圧縮可能な表面規則を選ぶが、対象・操作・目的・因果の意味同一性を与えない。
3. 語順変更では同じ変数の役割対応が失われ、gap の順序と意味役割を区別できない。
4. 主語省略では欠落変数を談話状態から復元する機構がない。
5. 250 frame まで増やしても完全一致 0 であり、探索幅不足ではなく評価関数不足が主要因。

## 系列B固有の進展

- 単層残差から上位可逆フレームへ拡張しても、表面圧縮だけでは意味境界の完全転移に届かないことを実測した。
- 候補 parse を少数保持する原理自体は低コストで、約5候補・0.083 ms/query・13 KBで動作した。
- **階層性の追加ではなく、異なる表面フレームを同じ潜在操作として結ぶ証拠が不足している**とボトルネックを絞り込んだ。

## 他系列へ返す知見

- A: future prediction は parse の再順位付け信号として使えるが、identity可逆性を独立制約にする必要がある。
- C: 介入同値性は異なる語順・表現のフレームを同じ操作へ商写像する候補信号になる。
- D: 高速束縛へ書き込む前に、複数 parse の不確実性を保持し、後続観測で再固定化する必要がある。
- E: learned constraint factor は literal一致ではなく、可逆再構成・介入結果・将来予測の合意から誘導すべき。

## 次仮説

**Cross-View MDL Program Quotient**

単一テキストの圧縮を捨て、同一episodeについて得られる複数view（言い換え、前後状態、後続発話、介入結果）の全てを、同じ潜在プログラムが説明できる場合だけフレームを統合する。

次サイクルでは、表面LCSではなく次を同時最小化する候補プログラム商空間を反証する。

1. 各viewの可逆再構成長
2. episode identityの局所束縛長
3. 介入前後差分の説明長
4. 後続予測誤差
5. プログラム再利用長
