## 新仮説

**Corpus-global MDL Residual Anchoring**:

文対を直接比較して差分spanを作る代わりに、コーパス全体で記述長を削減し、かつ左右文脈の多様性を持つ反復substringを「圧縮アンカー」として誘導する。新しい入力では、互いに重ならないアンカー集合を重み付き区間選択で求め、アンカー間に残る未見表面を変数候補として生成する。

この方式は、学習時に一度も現れなかった名称でも、既知substringの列挙ではなく**入力上の新規残差区間**として候補化できる。

## 既存方式との差

- PR #141のpairwise anti-unificationを使わない。
- 変数候補を学習済みsubstringから選ばない。
- 固定slot、形態素解析、辞書、意味ラベルを使わない。
- 全文を可逆に再構成できるアンカー＋残差分解を保つ。

## 実装

`mdl_anchor_experiment.py`

1. 文字substringを全コーパスから列挙する。
2. 反復による記述長利得と左右文脈多様性を計算する。
3. 上位アンカーを辞書化する。
4. 入力ごとに重み付き区間選択で非重複アンカー列を選ぶ。
5. アンカー間の残差を未知変数候補として出力する。

学習器が見るのは生文字列だけで、gold spanは評価時のみ使用した。

## 実測

3 seed（1 / 7 / 19）、学習160文、各評価80文。

| 指標 | MDL残差アンカー | pairwise反統一baseline |
|---|---:|---:|
| 未知名称 span F1 | **0.9453** | 0.8451 |
| 未知名称 完全一致 | **0.5750** | 0.0000 |
| 言い換え span F1 | **0.7341** | 0.7096 |
| 言い換え 完全一致 | **0.0000** | 0.0000 |

資源:

- serialized model: 平均 **6,032 bytes**
- 学習時間: 平均 **0.0130秒**
- 推論: 平均 **0.0507 ms/query**
- 誘導アンカー: 平均 **235**
- Peak RSS: **395,172 KiB**（Python/Jupyter実行環境込み。方式固有メモリではない）

## アブレーション

左右文脈多様性を1から3へ上げると、アンカー数が300から235へ減りながら、未知名称F1は0.9155から0.9453へ改善した。単なる高頻度substringより、異なる周辺文脈へ再利用されるsubstringをアンカーとする方が残差境界に有効だった。

min_countを8へ上げるとモデルは約3.4KBへ縮小したが、言い換えF1が0.7341から0.7282へ低下した。

## 反証・限界

仮説は**限定的支持**であり、汎用知能原理としては未達。

1. 未知名称のspan F1は高いが、完全一致は57.5%に留まる。
2. 文法自体を言い換えた評価では完全一致が全seedで0。
3. アンカー残差は「変数らしい表面区間」であり、対象・操作・目的・因果という意味を同定していない。
4. 候補を実行するプログラム、自由な日本語realizer、対話状態、計画、反実仮想、継続学習がない。
5. synthetic familyの構造規則性に依存しており、実コーパスで同じ精度を期待できない。
6. 文字substring辞書なので、このまま拡張するとアンカー辞書と候補照合が増大する。

- PR #139: 可逆なsurface bindingと潜在programを分ける必要がある。今回はアンカー＋残差で入力の可逆性を維持した。

## 他系列へ返す新知見

- 未知表面境界の生成には、候補substringそのものではなく、**再利用可能な固定部分を先に説明し、説明されない残差を候補化する相補的生成**が有効。
- 高頻度だけでなく左右文脈多様性を要求すると、辞書縮小と未知境界F1が同時に改善した。
- 一方、固定部分の圧縮だけでは文法言い換えを扱えないため、Aの予測状態、Cのイベント不変性、Eの複数分解競合を取り込む場合も、未知残差生成と構造一般化を別指標にすべき。

## 次に深掘る一点

**単一substringアンカーを、可逆な階層文法規則へ昇格させる。**

次サイクルでは、アンカー辞書の一致ではなく、複数文にまたがる部分導出木をMDLで共有し、未知入力について複数の完全可逆な導出をbeamで生成する。評価は実日本語コーパスで、表面renameだけでなく語順変更・省略・入れ子への境界転移と再構成率を測定する。
